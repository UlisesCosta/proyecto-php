### Descripción
Sitio web desarrollado con PHP para demostrar el funcionamiento de variables, tipos de datos, estructuras de control, arreglos y sesiones.

### Tecnologías utilizadas
- PHP
- HTML5
- CSS3
- InfinityFree

### Módulos del proyecto

| Archivo | Descripción |
|---|---|
| index.php | Página principal e inicio de sesión |
| variables.php | Variables y tipos de datos |
| condicionales.php | Estructuras condicionales |
| bucles.php | Ciclos y estructuras repetitivas |
| arreglos.php | Arreglos indexados, asociativos y multidimensionales |
| sesiones.php | Manejo de sesiones PHP |

### Estructura
- css/: hojas de estilo.
- includes/: componentes compartidos y manejo de sesiones.
- img/: recursos gráficos.

### Ejecución local
Iniciar el servidor PHP desde la carpeta del proyecto:

```bash
php -S localhost:8000
```

Abrir http://localhost:8000 en el navegador.
