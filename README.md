### Descripción del proyecto
Sitio web desarrollado con PHP para demostrar la aplicación práctica de los fundamentos del lenguaje, mediante ejemplos ejecutables de variables, tipos de datos, estructuras de control, arreglos y manejo de sesiones.

### Temas PHP implementados

El proyecto aborda los siguientes temas:

**1. Variables y tipos de datos**
- Declaración y asignación de variables.
- Tipos de datos: `string`, `int`, `float`, `boolean` y `array`.
- Visualización del contenido de variables mediante `echo`.
- Uso de las funciones `date()` y `count()`.

**2. Estructuras de control**
- Condicionales: `if`, `else` y `elseif`.
- Estructura de selección múltiple: `switch`.
- Evaluación de condiciones mediante variables y arreglos.

**3. Estructuras repetitivas**
- Ciclos `for`, `while` y `foreach`.
- Recorrido de listas y arreglos.
- Generación dinámica de contenido mediante ciclos.

**4. Manejo de arreglos**
- Arreglos indexados.
- Arreglos asociativos.
- Arreglos multidimensionales.
- Recorrido de arreglos mediante `foreach`.
- Uso de estructuras condicionales dentro de los recorridos.

**5. Manejo de sesiones**
- Inicio de sesiones mediante `session_start()`.
- Almacenamiento y consulta de información mediante `$_SESSION`.
- Registro de la hora de inicio de sesión utilizando `time()`.
- Visualización de la hora de inicio, hora actual y tiempo activo del usuario.
- Cálculo del tiempo transcurrido en minutos y segundos.
- Destrucción y reinicio de sesiones mediante `session_destroy()`.

### Estructura del proyecto
- `css/`: hojas de estilo.
- `includes/`: componentes compartidos y manejo de sesiones.
- `img/`: recursos gráficos.

### Ejecución local

Iniciar el servidor PHP desde la carpeta del proyecto:

```bash
php -S localhost:8000
```

Abrir [http://localhost:8000](http://localhost:8000) en el navegador.
